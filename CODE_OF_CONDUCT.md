# Code of conduct

Eolietech follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind and patient, assume good faith, criticise ideas and code rather than people, and
leave out harassment, insults and personal attacks of any kind. This applies in issues, pull
requests, discussions and anywhere else you represent the project.

## Reporting

If someone's behaviour bothers you, write to info@eolietech.com. Reports are read by the maintainer
only and kept confidential. The maintainer may edit or remove comments, close threads and block
accounts that break this code, as described in the Contributor Covenant's enforcement guidelines.
